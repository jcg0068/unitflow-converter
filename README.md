# UnitFlow Converter

UnitFlow Converter es una aplicación sencilla creada para convertir diferentes tipos de unidades de forma rápida y clara.  
El proyecto se desarrolló con ayuda de herramientas de IA como parte de una práctica de control de versiones con Git.

##  Funcionalidades
- Celsius → Fahrenheit  
- Fahrenheit → Celsius  
- Kilómetros → Millas  
- Millas → Kilómetros  
- (Rama feature-update) Metros → Centímetros y viceversa
